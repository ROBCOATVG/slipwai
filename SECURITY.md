# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for
[ROBCOATVG/slipwai](https://github.com/ROBCOATVG/slipwai/security/advisories/new).
Include enough detail to reproduce the problem and assess its impact.

We will acknowledge the report, investigate it privately, and coordinate
disclosure after a fix is available. If private vulnerability reporting is not
available yet, wait for it to be enabled rather than publishing exploit
details in an issue.

## Supported versions

Until the first public release, only the current `main` branch is supported.
After 1.0.0, the latest released version is the supported line.
