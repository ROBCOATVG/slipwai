# Canonical toolkit examples

These 141 snippets are the examples the toolkit's prose was written around, brought back from
`e1a9e43:assets/languages/typescript/examples/`. They are guidance expressed in TypeScript, not an installed
language's answers. Adoption resolves every marker here before any service or language package exists;
the project's skills label the examples as pseudocode for its own languages.

Generated services still resolve their examples from their selected language packages, including framework
overrides. This tree lives outside `assets/toolkit/` so projects receive resolved guidance, not an extra copy
of the snippet catalogue. Every toolkit and profile marker is held to this tree by `test_canonical_examples`.
