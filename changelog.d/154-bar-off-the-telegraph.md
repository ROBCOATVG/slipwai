**Ringing the telegraph no longer changes what may merge unfixed, and some findings are never stowed
whatever the bar.** The severity bar used to be one of each position's numbers: `full-ahead` set it to
`HIGH`, so a project rung up for throughput quietly began stowing every MEDIUM finding into the careen. On
one real run that was forty-six of them, among them a coerced request body that countersigned an
agreement, a control character that forged a line in a signed PDF, and a rounding error that fed a
valuation. The bar is now its own setting. It is `MEDIUM` unless a person changes it with
`slipwai telegraph --set bar=HIGH`. No ring and no banking of the fires moves it, and `slipwai telegraph`,
`slipwai fleet` and the board's Speed tab show it beside the position. A bar that is not a severity is
refused. Separately, a finding that leaves a feature unusable or untrustworthy for its actor is never
deferred. That covers a CRITICAL, as before. It now also covers these kinds, whatever their severity:
`validation-bypass` (input coercion or validation bypass on a state-changing route), `document-forgery`
(forgery or injection into a generated PDF or email), `erasure-leak` (personal data surviving or leaking
after deletion) and `money-arithmetic` (wrong arithmetic in a money figure). Each parks or is fixed like a
finding above the bar. `/adversary`, the budget section of `/sail`, the capability gates and the careen
page all say so.

**Catch-up:** run `slipwai migrate` to get the new `scripts/agents/telegraph.py` and the reworded
`commands/adversary.md`, `commands/sail.md` and careen pages. Your `harbour.json` keeps its `bar`. If it
reads `HIGH` because you rang `full-ahead`, or `LOW` because you rang `dead-slow` or `stop`, then a position
chose it, not a person. Put it back with `slipwai telegraph --set bar=MEDIUM`. Leave it only if somebody
chose that bar on purpose. Then reopen any row in `fairways/*/careen.md` whose finding is one of the four
never-stowed kinds: it was stowed by the old rule and is now owed before the capability is done.
