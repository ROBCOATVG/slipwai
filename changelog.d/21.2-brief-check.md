**`slipwai brief check <dir>` says what `generate --brief` will read from a folder, before anything is
generated.** Five lines: the requirements document and how it was found, the surfaces and the states on
their pages, the look, the people and the facts, and what the draft will have to assume because the
document says it left it open. It reads with the same sorting, the same page reader and the same limits as
the generate, so a page it counts is a page the board can approve. A folder with no document is an answer,
not a refusal; a page with no state article is one state, `shown`, and the line names it. The page reader
itself now lives in one module, `drawn.py`, so the Voyage window's approve button, the upstream stop and
this verb cannot read a page three ways.

**Catch-up:** nothing; it is a verb of the command, which `slipwai upgrade` brings.
