**The keel speaks the Agent Client Protocol's client half.** `slipwai.acp` is one session of whichever
coding agent a person has: it spawns the agent, shakes hands, opens or loads a session, puts each turn as
a prompt and hands every update to the caller as it arrives; it answers the agent's permission requests by
a policy — a write inside the working directory is allowed this once without a word, anything else goes
to the person — and its questions by handing them to the person, and it cancels a turn the way the
protocol requires, answering every open permission `cancelled`. Written with the standard library: the
keel still ships with no dependencies. Nothing on the board uses it yet; the slices after this one move the
first page, the console and then the stages onto it.

**Catch-up:** nothing; no project file changes.
