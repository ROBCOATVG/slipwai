**The harness registry says how each coding agent is launched over the Agent Client Protocol.** Every row
gains an `acp` column: an `npx` package with its arguments, or a binary with its arguments, copied from the
protocol's own registry on the date the row says, with whether it is the agent itself or an adapter, and
`proven: false` until a session has run on it from the board — 24 of the 36, Junie and Kiro among them,
which have no headless row. The twelve without say why. `slipwai.harness.acp_launch` turns a row into the
command this machine can make, or a sentence naming what is missing: Node for a package, the binary for
the rest. Nothing reads it yet; the settings page and the sessions after this do.

**Catch-up:** nothing; a generated project's copy of the registry gains the column on its next `migrate`,
and no script in a project reads it.
