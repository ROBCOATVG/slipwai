**The board gains a Settings tab: which coding agent its conversations run on.** *Runs on* lists every
harness the registry can launch as an Agent Client Protocol agent, each with where this machine found it
or what is missing — Node for a package, the binary for the rest — and *Auto*, the first found, as the
default. The model beside it is only ever one the agent itself offered when a session began; the board
names none of its own. Saved to `~/.slipwai/board.json`. A project's own answer to `./init` still wins
for its console. Nothing here is required: a board with no file, or no agent it can launch, runs its
conversations as it did before and says so on the page.

**Catch-up:** nothing; the board is served from the installed command.
