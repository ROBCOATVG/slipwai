**The first page's conversation runs over the Agent Client Protocol, on whichever agent the Settings tab
names.** Where this machine can launch one, the page's session is that agent's: the eight steps go at the
head of its first prompt, and every update the agent sends is on the page as it happens — its words, a
tool call as a line that changes colour as it runs, its plan as a list that ticks. A permission the board
cannot grant on its own, a write outside the sketch's folder, is a card with the agent's own options; a
question the agent asks is a card with a box to answer in, and the conversation goes on in the same
session. A turn under way has a Stop. The session is kept beside the brief, so a board restart loads it
where the agent can, with the history the agent replays. The page says which agent it is on. Where no
agent can be launched, the page runs as it did, on `claude` by name, and says so.

**Catch-up:** nothing; the board is served from the installed command.
