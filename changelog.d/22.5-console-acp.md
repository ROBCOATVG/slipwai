**The console runs over the Agent Client Protocol too, on the project's own agent.** The dock on the
Voyage page is a session of the harness the project's `./init` recorded, where this machine can launch it,
and of the Settings tab's agent otherwise. It can still read and cannot do: a read or a search is allowed
as it was, and any permission for a change is refused with the agent's own reject option and said on the
dock. What the agent reads shows as it reads it, a question it asks is a card, a turn has a Stop, and the
dock says which agent it is on. The session is kept under the project's `.slipwai/console/`, so a board
restart loads it where the agent can. With nothing to launch, the dock runs as it did, on `claude` by name.

**Catch-up:** nothing; the board is served from the installed command.
