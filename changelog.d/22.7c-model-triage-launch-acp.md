**The model, triage and launch run over the Agent Client Protocol from the board, as the draft does.**
Where the board can launch the project's agent, approving a storyboard, Send on the Feedback card and
Continue the build are sessions of it, with the agent's words and work on the receipt, its questions as
cards, and a Stop. The model is asked with the project's own script's prompt (`scripts/agents/model.py
--prompt`), less the sentence written for a session with nobody to ask; triage is given the numbers nobody
has routed; a launch charts and splits over the protocol and then enables `/cruise` and casts off as the
script does. A stage that ended without what it was for — no slice in the model, a record left unproposed,
no split — is a failed step that says so, and each stage's end is said in its own words rather than a
`make`'s. A running model or drawing is seen from another window of the project by the same marker the
scripts write. The scripts from a terminal, and every stage on a project whose agent has no launch row, run
as they did. The adoption steps and the captain's drives still run headless.
