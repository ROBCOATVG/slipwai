**An adoption step only the agent can take runs over the Agent Client Protocol from the board.** The
build floor, `smoke`, the parity list and the rest of what a decided strategy hands to the agent are, where
the board can launch the project's agent, sessions of it: the agent's reading and writing on the receipt
as it goes, a question only the person can answer as a card, and a Stop. The step is asked with the
project's own script's prompt (`scripts/agents/step.py --prompt`), so the words are one place's. The chain
still reads the tree afterwards, and the step is done when the tree says so. A project whose agent has no
launch row, and the script from a terminal, run as they did.

**Catch-up:** `scripts/agents/step.py` gains `--prompt`; an adoption refreshed before it runs its steps
headless from the board until `slipwai adopt --refresh` writes the script again.
