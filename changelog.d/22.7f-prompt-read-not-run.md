PATCH

**The board reads a project's script for its prompt flag before it runs it.** The model stage and the
adoption step ask the project's own script for their prompt with `--prompt`. A project generated before
that flag existed keeps the older script, which ignores its arguments and runs the stage: asked for its
prompt, it started the very session the board was about to start, under a timeout that killed it thirty
seconds later, and the Voyage meanwhile showed the run as somebody else's. The board now reads the script's
text for the flag and never runs a script that does not know it; such a project runs its stage headless,
once, as before.

**Catch-up:** nothing; `slipwai migrate` carries the scripts with the flag in.
