**Make ready and Sign in, on the Settings tab.** Under each agent this machine can launch, *Make ready* does
the handshake once, ahead of the first conversation — the agent started exactly as a session starts it,
through the board's own client, in a folder of the board's — and keeps what the agent said of itself: its
name and version, how long it answered in, whether it can pick a conversation up again, and the ways it
offers to sign in. An agent fetched with `npx` is fetched here, with its lines shown, so the first turn of
somebody's first conversation is not also a download. *Sign in* calls the agent's own `authenticate` for
a method of its kind; for a method of the terminal kind the page shows the one line to run. An agent that
cannot start is a recorded fault on its row, and one this machine cannot launch gets no button.

**Catch-up:** nothing; the board is served from the installed command.
