**A run stops waiting on a person for things that were never a person's.** One afternoon of a real run left
104 items under *Waiting on you*, and about three of them were decisions. The rest were these.
- **A slice could not say it was built.** `mark-set` and `demo` had no command, so a session appended them to
  the log by hand, and a harness that judges each action refused a session editing the record it is judged
  by. `python3 scripts/agents/deck_line.py mark-set --slice <id> --mark <mark>` and `… demo --slice <id>
  --verdict <verdict>` write them now, held to the chart's `sets` and the three verdicts; `/sail`, the
  captain's and the watch's briefs, the stop hook and the gate's own refusals name them.
- **A mark is set once.** The gate asked for every `mark-set` again on every run. A mark already in the
  slice's log stands; the `demo` line is still owed by each run, since it is the one that is true of this
  head.
- **A park was lifted that trunk had nothing to do with.** A merge refused on a red trunk cleared every later
  park on that fairway once trunk was green, whatever it was for, so a slice that could not pass its gate
  was dispatched about once a minute and `attempts` bounded nothing. One refusal now clears the one park it
  caused.
- **The usage limit was read as a crash.** `You've hit your 5-hour limit · resets 6:50pm` names none of the
  words the pause looked for, and a limit said as the last line of a turn that ended normally was not
  looked at at all. Five fairways spent their attempts in seconds and parked. Any limit that was hit or
  that says when it resets is a pause until then, with no attempt spent.
- **The mender failed where it had succeeded, and could not start where it was needed.** Every need it
  landed was sent a second mender, which found nothing to do and was recorded as a failure. A landed
  branch was never deleted, and a need was named by its fairway and position alone, so the next hand-back's
  first need met a branch already called that and never started. A landed need is not tried again, its
  branch goes, each need's branch carries its own hand-back's instant, and a feature's mock-ups are a
  shared surface the mender may land.
- **The same note said again was listed again.** A hand-back asking for exactly the same thing is one row,
  the newest, and answering it answers the earlier ones.
- **A story's dates went stale, and a berth's seed reached another berth's database.** `try-it.json` may
  write a date relative to the day it runs — `{today+3}`, `{next-thu}`, `{next-thu+7}` — and `try_it.py seed
  --slice` and `people` run with what their caller exported ahead of `.env.example`.
- **The captain asked for `/drive`.** The command has been `/sail` since the rename and the word stayed in
  the captain's prompt, so a harness that takes slash commands was sent one no project has.

**Catch-up:** `slipwai migrate` brings the command, the gate and the wording. Then, for a slice that is
built and parked for a line it could not write, write the line with `deck_line.py` and start the fleet
again; a story with fixed dates in its `try-it.json` can take the relative ones. Branches named `mend/*`
left by earlier runs are safe to delete once their work is on trunk.
