**`/drive` chooses and records how many rules one implementation delegate is handed — a task, a rule, or every
rule of one user story — and a project can declare an experiment on its own method that the ladder reads, asks
about, records and switches off.** A project running the generated workflow measured most of a slice's
implementation wall as each fresh delegate re-reading the same plan, map, precedent and test file, one task at
a time. The story boundary answers that while moving nothing else: the increment stays the rule, stub-first,
each example failing for its own reason. The ladder says which boundary it hands a delegate, defaults to the
story where the map is rule-owned and the tasks carry story tags, and puts the boundary and the delegate's
fan-out on the implement entry as `arm=` and `split=N`, so a wall time says what it was a wall time of. Where
`.specify/experiment.md` exists — a hypothesis, arms that each move one variable and state every licence in
full, what does not change between arms, a control arm and a stop condition — `/drive` runs
`scripts/agents/benchmark.py arms`, asks which arm every slice runs, says which arm has gone unrun, records the
answer, and stops the experiment when the control arm is answered rather than offering a revert that decays at
the next commit. `make benchmark` gains an arm column and a note when a slice ran as two arms.

With it, four smaller things the same project reported. The generated Makefile names its Go modules once, in
`GO_MODULES`, and both `lint` and `format` read it, so the two can no longer cover different paths. `./init`
installs Spec Kit at the release `project.json` now records as `speckitSource`, so restoring the ignored
projections is no longer a silent upgrade to upstream HEAD; `SPECIFY_SOURCE` still overrides it. The
extension contract gains its sixth obligation: a file the user must hand-edit is a merge target, never a write
target. And the event-model renderer says which variable to set when Chromium refuses to start as root.

**Catch-up.** `project.json` gains `speckitSource` through the merge; a project that wants to stay on the Spec
Kit it has edits the value before its next `./init --integration`. `make format` and `make lint` now read
`GO_MODULES`: a Go module the project added under `packages/` by hand goes on that line, once. Nothing else
asks anything of a repository already generated.
