PATCH

**Installing a tool from the board shows that it is doing something.** The card said *Fetching…* and then
nothing until the end, and sixty megabytes of Git on a slow line was a minute of one unchanging line. It now
names the step under way — asking the publisher, downloading, checking, unpacking, finishing — with a bar
that fills as the download comes, *Downloading: 23 of 60 MB*, and how long a step that cannot be counted has
been running. An install is followed after the page is reloaded or opened in a second window, where the
card used to say *is being installed now* and stop. One that fails stays on the page with its reason, and
the button comes back; reloading on every ending took the reason away.

**Git on Windows installs where its archive cannot be deleted at once.** Windows refused to delete the
PortableGit archive a moment after it had unpacked itself, and that was reported as the install failing:
Git sat unpacked and unrecorded. The archive is tried again for a few seconds and then left; the install
stands.

**A tool the board has just installed is found without starting the board again.** After installing Node,
Settings went on saying *there is no `npx` on PATH: install Node*, and a sketch or console went on running
without it, because the board read its tools once when it started.

**Catch-up:** nothing; install the new build.
