**Projects on Windows, through Git Bash.** A generated project runs the same `./init`, Makefile and
scripts on Windows as on a Mac, under the bash that comes with Git for Windows. The board counts Git only
where it carries bash, and installs PortableGit where it does not; it installs GNU Make, checksum-checked,
and gives bash a `python3`. It starts a project's scripts through bash and finds every program on its
children's `PATH`, and the *This machine* card offers *Open a terminal here* in place of the note about WSL.
A generated project carries a `.gitattributes` that keeps its scripts at LF on a Windows checkout, `./init`
asks Spec Kit for its sh scripts under Git's bash, and Try it, the moorings and the harbourmaster stop
processes and link folders in ways Windows allows. Nothing changes on macOS or Linux: every file a project
runs there is held to its bytes, or to a recorded reason, by a new fence.

**Catch-up:** `slipwai migrate` adds the `.gitattributes`.
