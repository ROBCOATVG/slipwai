# The factory's own development tooling, pinned exactly as a generated project's is. Installed into
# `.python-tools` by `scripts/verify`, which is what `make lint` and `make verify` run.
#
# Same ruff the generated Python project gets, deliberately: the factory should not be checked by a
# looser tool than the one it hands its own output.
ruff==0.16.3
# The type checker. Nearly everything here is a string — an axis, a feature, a backend key, a language
# family — and the distinction between two of them (`java-spring` the backend, `java` the family) is one
# this package leans on everywhere. mypy is what catches a backend handed where a family was meant, and
# an Optional read as though it were not; `compileall` catches neither.
mypy==2.3.1
# The suite reads YAML that nothing in `src/` does: the four workflow files `test_backstop.py` holds, the
# chart `test_chart_render.py` renders, and the model `test_loop.py` drives a captain against. It was not
# pinned here, so those tests ran on a laptop that happened to have PyYAML and errored in CI, which is the
# shape of failure this file exists to stop — a gate that proves less on the machine that matters.
PyYAML==6.0.3
# The session-limit refusal names its reset in a zone — `resets 9:40pm (Europe/London)` — and `zoneinfo`
# reads that zone from the system's tz database, which Windows has not got. Without this the gate's
# Windows runner fell back to its own clock and paused every limit an hour out. Unix has the database
# and ignores this package; Windows reads it.
tzdata==2025.2
